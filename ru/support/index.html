Поддержка

Shelfy живёт в строке меню. Копируйте как обычно, а потом нажмите ⌘⇧V — или щёлкните значок Shelfy в строке меню и выберите «Показать историю».

Вставка

  • ← → — выбрать элемент
  • Return или двойной клик — вставить
  • Shift+Return — вставить без форматирования
  • ⌘1…⌘9 — быстрая вставка
  • Esc — закрыть шторку

Не работает автовставка

Чтобы Shelfy вставлял выбранный элемент сам, ему нужно разрешение «Универсальный доступ». Откройте Системные настройки → Конфиденциальность и безопасность → Универсальный доступ и включите Shelfy. Без разрешения элемент копируется в буфер — вставьте его через ⌘V.

Теги

Правый клик по карточке → Тег, чтобы назначить тег или создать новый. Tab переключает теги. Элементы с тегом хранятся бессрочно; управлять тегами можно в Настройках → Теги.

История и приватность

Срок хранения выбирается в Настройках → Основные. «Очистить историю…» удаляет все элементы без тегов. Всё хранится только на вашем Mac, а пароли, помеченные менеджерами паролей как скрытые, не сохраняются. Приостановить запись можно через значок в строке меню → Приостановить запись.

Язык

Shelfy использует язык вашего Mac. Чтобы выбрать язык только для Shelfy, откройте Системные настройки → Основные → Язык и регион → Программы.
