Soporte

Shelfy vive en la barra de menús. Copia como siempre y pulsa ⌘⇧V, o haz clic en el icono de Shelfy en la barra de menús y elige «Mostrar historial».

Pegar

  • ← → — elegir un elemento
  • Return o doble clic — pegar
  • Mayúsculas+Return — pegar como texto sin formato
  • ⌘1…⌘9 — pegado rápido
  • Esc — cerrar el panel

El pegado automático no funciona

Para pegar el elemento seleccionado por ti, Shelfy necesita acceso de Accesibilidad. Abre Ajustes del Sistema → Privacidad y seguridad → Accesibilidad y activa Shelfy. Sin él, el elemento se copia al portapapeles y puedes pegarlo con ⌘V.

Etiquetas

Haz clic derecho en una tarjeta → Etiqueta para asignar una etiqueta o crear una nueva. Pulsa Tab para cambiar entre etiquetas. Los elementos con etiqueta se conservan para siempre; gestiónalas en Ajustes → Etiquetas.

Historial y privacidad

Elige cuánto tiempo conservar el historial en Ajustes → General. «Borrar historial…» elimina todos los elementos sin etiqueta. Todo se guarda solo en tu Mac y las contraseñas marcadas como ocultas por los gestores de contraseñas nunca se guardan. Para pausar el registro, usa el icono de la barra de menús → Pausar el registro.

Idioma

Shelfy usa el idioma de tu Mac. Para elegir un idioma solo para Shelfy, abre Ajustes del Sistema → General → Idioma y región → Aplicaciones.
